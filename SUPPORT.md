# Support

Where to get help with **mav-voice-gcs**:

1. **Documentation first** — most answers live there:
   - [README](README.md) — installation, configuration, usage;
   - [docs/CONFIGURATION.md](docs/CONFIGURATION.md) — every config key;
   - [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — how it works inside;
   - [docs/MANUAL_TESTING.md](docs/MANUAL_TESTING.md) — step-by-step
     acceptance testing, including SITL setup.
2. **Found a bug?** Open an issue using the
   [bug report template](https://github.com/EgorLikhachev/testTask/issues/new?template=bug_report.md).
   Attach application console output and, if possible, the `.tlog` session
   log (enable with `[log] enabled = true`).
3. **Missing a feature?** Open an issue using the
   [feature request template](https://github.com/EgorLikhachev/testTask/issues/new?template=feature_request.md).
4. **Security issues** — see [SECURITY.md](SECURITY.md); do not use public
   issues for them.

Community channels (Discussions/chat) may be enabled as the project grows —
issues are the canonical place for now.
